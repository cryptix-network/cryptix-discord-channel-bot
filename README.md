#Cryptix Channel Bot
This bot fetches and displays real-time data for the Cryptix network, including the latest price, hashrate, and 24-hour trading volume. It updates Discord channel names dynamically based on the latest values, providing live statistics in a visually organized format. With the use of slash commands, users can also request the current price and hashrate directly in Discord.

##Key features:

    Real-time Price Updates: Displays the latest price of Cryptix (CYTX) in USDT.

    Hashrate Tracking: Shows the current network hashrate for Cryptix.

    24h Volume Updates: Displays the total 24-hour trading volume in USDT.

    Dynamic Channel Name Updates: Keeps channel names updated with real-time statistics.

Designed to provide seamless integration with your Discord server, this bot helps keep everyone informed on Cryptix network stats.
